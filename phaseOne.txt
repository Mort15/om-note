system-view

 

1.创建VLAN：从无到有生成10/20/30/40/50虚拟局域网

 

vlan batch 10 20 30 40 50

 

2.端口划入VLAN：将物理接入端口分配至指定VLAN（终端口为Access模式）

 

interface GigabitEthernet 0/0/1

port link-type access

port default vlan 10

 

interface GigabitEthernet 0/0/2

port link-type access

port default vlan 20

 

interface GigabitEthernet 0/0/3

port link-type access

port default vlan 30

 

interface GigabitEthernet 0/0/4

port link-type access

port default vlan 40

 

interface GigabitEthernet 0/0/5

port link-type access

port default vlan 50

 

3.上联端口配置Trunk：允许多VLAN标签数据跨设备传输（二层→三层透传VLAN数据）

 

interface GigabitEthernet 0/0/24

port link-type trunk

port trunk allow-pass vlan 10 20 30 40 50

 

save

 

二、三层核心交换机（精准定义：创建对应VLAN、对接端口放行VLAN、配置VLANIF三层网关实现跨VLAN路由）

 

system-view

 

1.创建VLAN：与二层交换机保持一致，生成对应VLAN数据单元

 

vlan batch 10 20 30 40 50

 

2.对接端口Trunk放行：接收二层透传的多VLAN带标签数据

 

interface GigabitEthernet 0/0/1

port link-type trunk

port trunk allow-pass vlan 10 20 30 40 50

 

3.配置VLANIF虚拟三层接口（跨VLAN互通核心）：为每个VLAN配置网关IP，实现三层路由转发

 

interface Vlanif 10

ip address 192.168.10.1 255.255.255.0

 

interface Vlanif 20

ip address 192.168.20.1 255.255.255.0

 

interface Vlanif 30

ip address 192.168.30.1 255.255.255.0

 

interface Vlanif 40

ip address 192.168.40.1 255.255.255.0

 

interface Vlanif 50

ip address 192.168.50.1 255.255.255.0

 

save

TCP握手和挥手的基本规则：

1, seq序列号是给包设置的编号

2, 三个消耗seq的信号SYN-DATA-FIN

3, ack是预计对方下一个seq的值

4, a的seq和b的seq是相互独立的



启动三次握手流程:

a:[SYN] seq=1

b:[SYN, ACK] seq=2,ack=2

a:[ACK] seq=2,ack=3



TCP四次挥手流程:

b:[FIN] seq=1, ack=999

a:[ACK] seq=999, ack=2

a:[FIN] seq=999, ack=2

b:[ACK] seq=2, ack=1000



TCP延迟的情况下, ACK包可以携带FIN, 最后实现挥手过程是三次:

b:[FIN] seq=1, ack=999

a:[ACK, FIN] seq=999, ack=2

b:[ACK] seq=2, ack=1000
