fastcgi 代理配置语法
#可以用普通的IP+端口的形式
fastcgi_pass localhost:9000;
#可以以接口的形式来运行
fastcgi_pass unix:/tmp/fastcgi.socket;
fastcgi_index index.php; #默认返回index.php而不是index.html。
fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; #定义变量，NGINX通过php内置变量才能拿到用户的请求。
#就像RSYNC_PASSWD一样，PHP也是读取内部变量。
--------------------------
server {
	listen 80;
	server_name _;

	location / {
		root /code;
		index index.html index.php;
	}
}
location ~* \.php$ {
	root /code;
	fastcgi_pass 127.0.0.1:9000;
	fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name
	include fastcgi_params;
}

2026年7月30日15:40:23提炼:
主要新的内容:
1，匹配.php   \.转义特殊字符  php$后缀php结尾匹配 
2，~* 不区分php大小写的匹配
3，fastcgi_pass 127.0.0.1:9000; # fastcgi_pass proxy_pass 用法很像，并且都是pass结尾。
4，fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
主要就是记忆和理解最后一行:
SCRIPT_FILENAME 可以在phpinfo()里面看到，$document_root文档根目录,$fastcgi_script_name请求的脚本文件名.最后拼接在一起赋值给SCRIPTE_FILENAME
两类参数的来源是:SCRIPT_FILENAME 是php内置变量，可以在phpinfo看到
而$document_root和$fastcgi_script_name是nginx的扩展包的内置变量。
我草！我理解的这么准确吗？！！
推测过程:用NGINX常规变量的写法推断$开头的是内置变量;fastcgi是nginx可有可无的，所以是nginx扩展包;phpinfo包含的变量所以大写的SCRIPT_FILENAME是php内置变量。
include fastcgi_params; #定义了大量 CGI 标准变量，在conf文件能找到，其中包含$document_root和$fastcgi_script_name
--------------------------
location ~ \.php$ {
	root /usr/share/nginx/html;
	fastcgi_pass 127.0.0.1:9000;
	fastcgi_index index.php;
	fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
	include fastcgi_params;
}
