--------------- tomcat介绍 ---------------

1，本身就可以处理java动态数据
2，java跑在JVM
3，jvm是跑完整硬件系统的功能
4，jvm诞生是为了跨平台
5，([windows]+[linux]) * jvm
6，java编译一次 -> jar war 二选一，运行方式不一样 -> 都能放在JVM
7，jre包含jvm，jvm可以装在任何操作系统，
8，jdk包含全部，jre仅能运行，jvm是运行需求之一。
9，tomcat解析静态效率不如nginx，大部分是相结合。

--------------- 安装tomcat ---------------

mkdir /soft
tar -xf apache-tomcat-9.0.89.tar.gz -C /soft/
ln -s /soft/apache-tomcat-9.0.89/ /soft/tomcat

lib #jar包形式的插件扩展 如同 nginx 的模块
webapps/ROOT #tomcat 放代码必须放在这里
work #缓存
catalina #处理http请求
1，以前tomcat叫catalina; 2，寓意可能是想把Tomcat设计成一个优雅美丽且轻量级的web服务器
3，/usr/lib/systmd/system/tomcat.service
4，描述 前提服务 类型 启动 关闭 重启 

--------------- 配置systemctl tomcat---------------

cat >/usr/lib/systmd/system/tomcat.service<<EOF
[Unit]

Description=Apache Tomcat Server
After=network. target remote-fs.target nss-lookup.target

[Service]
Type=forking
ExecStart=/soft/tomcat/bin/startup.sh
ExecStop=/soft/tomcat/bin/shutdown.sh
ExecRetart=/soft/tomcat/bin/shutdown.sh
&& sleep2 && /soft/tomcat/bin/startup.sh

[Install]
WantedBy=multi-user.target
EOF
