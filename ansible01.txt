----------Playbook---------
playbook是ad-hoc的编排
playbook可以重复使用
playbook可以用package自动匹配需要的模块
冒号后面有东西，必须紧跟一个空格
冒号后面没东西，后面必须清空
空格最好一次空两次，原因很简单，因为横杠搭配空格正好是两个字符，此外官网也是空两个
- hosts: web01	#play: 指定客户端
  tasks:		#book: 具体执行的动作
    - name: install NFS-utils
      package:
        name: nfs-utils
        state: present
    - name: Configure NFS Server
      file:
        path: /data
        state: directory
- hosts: web02
  tasks:
    - name: xxx

- hosts: nfs
  tasks:
    - name: Install NFS Server
      yum:
        name: nfs-utils
        state: present

    # - name: Configure NFS Server
    #   copy:
    #     src: exports
    #     dest: /etc/exports
    #     owner: haha
    #     group: haha
    #     mode: 0600

    - name: Configure NFS Server
      copy:
        content: "/data/ 172.16.1.0/24(rw,sync,all_squash,anonuid=666,anongid=666)"
        dest: /etc/exports

    - name: Create www Group
      group:
        name: www
        gid: 666
        state: present

    - name: Create www User
      user:
        name: www
        uid: 666
        group: 666
        shell: /sbin/nologin
        create_home: false

    - name: Create /data
      file:
        path: /data
        state: directory
        owner: www
        group: www

    - name: Start NFS Server
      systemd:
        name: nfs
        state: started
		#started
		#stopped
		#restarted
		#reloaded
        enalbe: yes

#检查语法
ansible-playbook --syntax-check nfs.yml
